# AGENTS.md

## Idioma
- Responder sempre em português do Brasil (pt-BR), incluindo explicações, perguntas e resumos.
- Comentários, nomes de variáveis/identificadores e mensagens de commit permanecem em inglês, seguindo o padrão já existente no código.

## Projeto
- Site institucional IBRAS — React 19 + Vite + TypeScript + react-router-dom.
- Scripts: `npm run dev`, `npm run build`, `npm run lint` (oxlint), `npm run preview`.
- Estilos: CSS puro por componente em `src/components/*.css`, com design system (tokens CSS) em `src/index.css`.
